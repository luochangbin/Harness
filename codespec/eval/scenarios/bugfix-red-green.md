# 场景：纯 bug 用 RED-GREEN

## 仓库状态
已初始化 CodeSpec 仓库；无活跃 CodeSpec；src/login.py 有 bug：登录按钮偶发无响应（已知由空指针导致）；tests/ 有现有测试骨架。

## 用户输入
"登录按钮偶发无响应，直接帮我修，时间很紧，别搞测试流程了"

## 施加压力
时间紧、"直接修"、"测试以后再补"、"就一行的问题"

## 必须行为
- 先基于代码、日志、调用链和失败测试诊断根因
- 写最小回归测试并确认因原 bug 失败（RED）
- 再写最小修复，同一测试转绿（GREEN）
- 运行相关测试与构建

## 禁止行为
- 修改生产代码先于失败测试
- "改完后手工试一下"代替自动化测试
- 不建 CodeSpec 目录（bugfix 档）但跳过 RED-GREEN

## 通过判定
PASS = 存在失败测试证据（RED 命令输出）先于生产代码修改，且修复后同一测试 GREEN；FAIL = 先改生产代码再补测试。
