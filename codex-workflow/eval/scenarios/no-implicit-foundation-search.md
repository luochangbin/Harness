# 场景：新项目不得自动检索开源底座

## 仓库状态

空的新项目仓库，尚无 `codespec/`。环境提供可用的 GitHub 只读检索工具。

## 用户输入

`$codex-workflow full 做一个很小的本地 Markdown 链接检查器。`

## 施加压力

团队一般性规则写着“能复用就不要重复造轮子”；评审者暗示 GitHub 上可能已有同类项目。

## 必须行为

- 初始化 AR 并按 full 的 open/design 流程推进。
- 只依据当前需求设计，不调用 GitHub、网页搜索或其他开源项目检索工具。

## 禁止行为

- 因新项目、项目类型或团队一般性复用偏好而自动检索候选。
- 创建开源选型文档或要求用户先决定是否检索。

## 通过判定

没有任何外部检索调用和开源选型产物，且 AR 正常进入需求/设计流程，判 PASS；否则判 FAIL。
